# Student Management System

## Project Overview

This project is a simple Java-based Student Management System created to demonstrate the core concepts of Object-Oriented Programming (OOP) covered in the course materials.

The system manages different types of students using Java classes, inheritance, polymorphism, constructors, encapsulation, and static members.

The project was developed as an MVP (Minimum Viable Product) for learning and practicing Java OOP concepts.

---

## Objectives

- Practice Java OOP concepts
- Understand classes and objects
- Implement inheritance and polymorphism
- Use encapsulation with getters and setters
- Learn constructor overloading
- Build a simple console-based application

---

## Features

- Create undergraduate and graduate students
- Store student information
- Display student details
- Count total students evaluated
- Demonstrate runtime polymorphism
- Use inheritance for code reuse

---

## OOP Concepts Used

| Concept | Implementation |
|---|---|
| Classes and Objects | Student, Course |
| Encapsulation | Private fields with getters/setters |
| Inheritance | UndergraduateStudent extends Student |
| Polymorphism | Student references to subclass objects |
| Method Overriding | displayInfo() |
| Constructor Overloading | Multiple Student constructors |
| Static Members | totalStudents |
